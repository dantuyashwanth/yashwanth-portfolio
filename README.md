## 📂 Featured Projects

### 🍽️ AI-Powered Calorie Tracker

An intelligent calorie tracking application that uses image-based food analysis to identify food items and provide nutritional information such as:

- Calories
- Proteins
- Carbohydrates
- Fats

The project focuses on making calorie tracking easier using Artificial Intelligence and image recognition.

### 🖼️ Fake Logo Detection Using KNN

A machine learning project that uses the **K-Nearest Neighbors (KNN)** algorithm to help identify counterfeit logos.

The system analyzes logo features and classifies them to differentiate between genuine and potentially fake designs.
